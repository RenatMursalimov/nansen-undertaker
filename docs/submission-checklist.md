## 4. Публичный репозиторий (правила его ТРЕБУЮТ)

Правила конкурса: «Post on X, tag @nansen_ai + **link your repo**». То есть ссылка
обязательна, и «если потребуют» тут больше не про нас - этот пункт из условия.

Копия НЕ СОБИРАЕТСЯ РУКАМИ. Ручная выжимка - это форк: он разойдётся с ботом на первой
правке и разойдётся молча, а человек по ссылке будет читать код, которого у нас нет.
Собирает генератор, он же не даёт уехать лишнему.

- [ ] Пустой публичный репозиторий создан владельцем (агент этого не может: токен не даёт
      создавать репозитории, 403).
- [ ] Выжимка собрана генератором и проверена на месте:
      ```
      cd <BOT_DIR> && git pull
      ./venv/bin/python3 tools/export_nansen_public.py --out ~/nansen-undertaker
      cd ~/nansen-undertaker && python3 tests/test_public.py && python3 scrub.py
      ```
      Оба прогона зелёные: тесты без ключа и без сети, скруббер - без ников, боевых путей,
      чужих адресов и ключей.
- [ ] В выжимке нет `.env`, `nansen_credits.json`, каталога `nansen_tele/`, базы зачёта
      (всё в `.gitignore` выжимки, но проверить глазами один раз стоит).
- [ ] `MANIFEST.md` на месте: он говорит, что приехало байт-в-байт, что с заменой путей, а
      чего в боте нет вовсе.
- [ ] После правок слоя - `--check`: он краснеет, если публичная копия отстала. То же самое
      сторожит закон-тест в гейте на каждый push.
